# reports 索引

本目录存放**沉淀出来的经验内容**：阶段分析、专项复盘、跨任务教训、可复用决策证据。

与 `work-notes/` 的核心区别：`work-notes/` 是**经历**（当时做了什么），`reports/` 是**经验**（可复用结论）。

## 专题经验沉淀

- [no-littering 引入评估（决策：暂不采用）](no-littering-evaluation.md)

## 使用建议

1. 新增报告时在此索引中添加条目。
2. 想追踪当前做什么，转去 [`../specs/ROADMAP.md`](../specs/ROADMAP.md) 与 [`../jobs/README.md`](../jobs/README.md)。
3. 内容如果只是"当时做了什么"，归 `../work-notes/`；如果已提炼为可复用结论，归本目录。
