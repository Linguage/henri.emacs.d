# LaTeX-Diary Vendored Theme

- Upstream: https://github.com/cs-qyzhang/LaTeX-Diary
- Vendored from commit: `84395423c233105329b735b1e138cced4a712201`
- License: GPL-3.0; see `LICENSE`.

`diary.cls` and bundled assets are preserved from upstream.  `henri-diary.cls`
is a local adapter for Org Journal PDF export: it keeps the spiral diary
layout, resolves the icon font through `OSFONTDIR`, and adds commands used by
Org's LaTeX section mappings.
